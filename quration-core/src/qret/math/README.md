\page qret_math math module

Implements math-related functions and classes used by qret.

## Code map

- `qret/math/boolean_formula.h` : logical formulas
- `qret/math/clifford.h` : Clifford operations
- `qret/math/float.h` : floating-point approximation
- `qret/math/fraction.h` : continued fractions
- `qret/math/integer.h` : integers
- `qret/math/lcu_helper.h` : functions related to Linear Combination of Unitaries (LCU)
- `qret/math/pauli.h` : Pauli strings
